# Book Search Project

## 프로젝트 소개
도서 검색 API를 활용한 웹 기반 도서 검색 서비스입니다.  
사용자는 제목, 저자, 키워드를 기반으로 원하는 도서를 검색하고 상세 정보를 확인할 수 있습니다.

---

## 주요 기능
- 도서 검색 기능
- 도서 상세 정보 조회
- 반응형 웹 UI 지원
- API 기반 실시간 데이터 조회
